# Project 61

An independent creative + technology studio website.

## Status

**Version 0 / provisional direction.** Initial site architecture is published in this GitHub repository to simplify Vercel deployment. The visual identity, copy and project presentation have **not yet been approved** by the studio owners.

## What this site includes

- Responsive homepage with four service areas: video editing, data analysis, web development and software/automation.
- Selected work: Anticipate sports storytelling, automotive edits, Haliburton prediction, Anticipate website and NBA Time Machine.
- Project category filters.
- Client inquiry form that opens an email client. **There is no backend, database or automatic email delivery.**
- Basic accessibility, mobile navigation and social metadata.

## Deploy to Vercel

1. Sign in to https://vercel.com with your GitHub account.
2. Click **Add New → Project**.
3. Import **mudia-OE/Project-61**. If it doesn't appear, grant Vercel access to that repository in the GitHub integration.
4. Configure:
   - Project name: project-61 (or another available name)
   - Framework Preset: **Other**
   - Root Directory: **./**
   - Build Command: enable Override and leave it empty
   - Output Directory: leave at the default for a static project
   - No environment variables needed
5. Click **Deploy**.
6. Verify the generated *.vercel.app URL and open it on desktop and mobile.
7. Future commits to the production branch will redeploy automatically.
